OVERHEAT — installation sur Mac
===============================

1. Copier les fichiers :
   - OVERHEAT.vst3      ->  /Library/Audio/Plug-Ins/VST3/        (ou ~/Library/Audio/Plug-Ins/VST3/)
   - OVERHEAT.component ->  /Library/Audio/Plug-Ins/Components/  (ou ~/Library/Audio/Plug-Ins/Components/)
   - OVERHEAT.app       ->  où tu veux (version autonome, pratique pour tester)

2. Le plugin n'est pas signé par Apple : macOS peut le bloquer.
   Ouvre le Terminal et lance (adapte le chemin si tu l'as mis dans ~/Library) :

   sudo xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/OVERHEAT.vst3
   sudo xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/Components/OVERHEAT.component

3. Dans FL Studio : Options > Manage plugins > Find more plugins (rescan),
   puis OVERHEAT apparaît dans les effets (Fx > Distortion).

Contrôles
---------
- Glisser le DSR-50 vers le haut / le bas, ou cliquer la barre : la chauffe (0-100 %).
  Molette = réglage, Shift = réglage fin, double-clic = 0.
- À 100 % : clic sur l'arme = tir.
- THERMAL / TUBE / TAPE / FUZZ / GRIT : le grain de saturation.
- MIX : propre / saturé.   AUTO GAIN : garde le même volume perçu.   BYPASS.

Chauffe, mode, mix, auto gain et bypass sont automatisables dans FL Studio.
